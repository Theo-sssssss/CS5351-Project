# CS5351 Software Engineering Project

This repository contains a six-person team project for CS5351 Software Engineering.

## Project Status

The team will select a bounded, original software engineering tool that assists software developers or development teams. The tool must solve a measurable development-workflow problem; it is not an end-user application.

## Core Constraints

- Team size: 6 members.
- Effort: each member contributes approximately 30-40 productive hours.
- Process: at least three Agile sprints, with a standing weekly meeting and a burndown chart.
- Non-functional requirements: define at least two, each supported by an architectural design choice and rationale.
- Evidence: preserve weekly issues, plans, decisions, code, tests, reviews, risks, and unresolved technical debt in this repository.
- Delivery: source code on GitHub, a final report in IEEE Transactions on Software Engineering format, and a presentation/demo video.

## Working Structure

- `docs/project-requirements.md`: course requirements and team execution baseline.
- `docs/`: architecture, sprint records, evaluation plan, and report materials.
- `src/`: implementation after the project scope is selected.
- `tests/`: automated and acceptance tests after the project scope is selected.
