Webhook Automation

  1. After deployment, prepare a public HTTPS URL.
  2. In your GitHub repository, open Settings → Webhooks and create a webhook.
  3. Set the URL to /webhooks/github and select the Pull requests event.
  4. Use the same secret as PROMPT_REVIEW_GITHUB_WEBHOOK_SECRET.

Triggers: opened, reopened, synchronize.
